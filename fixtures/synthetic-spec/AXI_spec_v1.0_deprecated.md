# AXI4 Stream FIFO Controller Specification (DEPRECATED)

## Section 4.1 Flow Control & Backpressure (Requirement: AXI-BP-001-LEGACY)
- **ID**: `AXI-BP-001-LEGACY`
- **Scope**: AXI Stream Arbiter (Legacy Architecture)
- **Description**: Legacy v1.0 FIFO required fixed 4-cycle timeout when `tready` is held low. This specification is superseded by v2.1 (AXI-BP-002) and must not be used for current tapeouts.
