# Gate 3: Model A/B Benchmarking

## Objective
Benchmark candidate LLMs (e.g. Qwen 2.5 Coder 32B, Nemotron-4 15B, DeepSeek Coder V2) on identical benchmark cases, tool sandboxes, and token/turn budgets.

## Tracked Metrics
- Task Success Rate (%)
- Compilation Pass Rate (%)
- Simulation Pass Rate (%)
- Retry Count to Convergence
- Tool Error Rate
- Governance Violation Rate
